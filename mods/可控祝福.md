# 可控祝福

棋盘上决定前进点数的骰子（`Dice_Blessed_*` / `Dice_Cursed_*` / `Dice_Blursed_*` 等），其面为
`BoardGame.Elements.SOFaceResultCellEffect`（`digitResult` 点数 + `alterationSubType` 祝福/诅咒）。
本 mod 在房主端拦截该面效果执行，可**单独开关祝福 / 诅咒效果**，骰子照常出点数。

- **dll**：`InvokyrBlessControl.dll`
- **GUID**：`top.juluo.invokyr.blesscontrol`
- **插件名**：Invokyr Bless Control

## 效果

- 祝福面：可关闭（不给全员加血），点数正常。
- 诅咒面：默认关闭（不给诅咒），点数正常。
- 纯点数面（`Normal`）不受影响。

## 安装

把 `InvokyrBlessControl.dll` 放到（已替你放到）：

```
Steam\steamapps\common\Invokyr\BepInEx\plugins\可控祝福\InvokyrBlessControl.dll
```

重启游戏，由房主开一局即可。

## 配置

首次运行后生成 `BepInEx\config\top.juluo.invokyr.blesscontrol.cfg`：

| 键 | 默认 | 说明 |
|---|---|---|
| `General:Enable` | `true` | 总开关 |
| `BoardDice:BlessHealAmount` | `50` | 祝福面给全员加的血量；**设 0 = 关闭祝福效果**（点数正常） |
| `BoardDice:CurseEnabled` | `false` | 诅咒面是否生效；默认关闭诅咒（点数正常） |

## 验证

日志 `BepInEx\LogOutput.log` 中应看到：

```
[InvokyrBlessControl] loaded. ...
[BlessControl] board blessing face: healAmount=... -> effect=native|removed
[BlessControl] board curse face: curseEnabled=...
```

## 已知边界

祝福加血 50 在 **native 方法内部**（`SrvExecuteEffect`），当前版本支持「设 0 关闭 / 默认 50 原生」。
把加血量改成任意数值（如 30）需要拦截玩家加血 API，属后续版。

## 卸载

删除 `BepInEx\plugins\可控祝福\` 整个文件夹即可。
