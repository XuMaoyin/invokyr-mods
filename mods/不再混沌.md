# 不再混沌

让**新出现的骰子里不再有混沌（多效果混合）功能骰子**；存档里已有的混沌骰子保留不动。

- **dll**：`InvokyrNoChaosDice.dll`
- **GUID**：`top.juluo.invokyr.nochaosdice`
- **插件名**：Invokyr No Chaos Dice

## 效果

- 房主打开棋盘（`DiceBox`）及骰子生成时，把混沌骰子从发放源头剔除 → 之后**新发放选不到混沌骰子**。
- **房主安装即可，所有客户端自动生效**（挂钩服务端骰子池，跑在房主）。
- 判定按骰子**身份（名字/别名）**封禁，**不数面**——因为正常功能骰子也带 debuff 面；棋盘点数/诅咒/祝福骰子属另一系统，完全不动。

## 安装

把 `InvokyrNoChaosDice.dll` 放到（已替你放到）：

```
Steam\steamapps\common\Invokyr\BepInEx\plugins\不再混沌\InvokyrNoChaosDice.dll
```

重启游戏，由房主开一局即可。

## 配置

首次运行后生成 `BepInEx\config\top.juluo.invokyr.nochaosdice.cfg`：

| 键 | 默认 | 说明 |
|---|---|---|
| `General:Enable` | `true` | 总开关 |
| `General:BlockMultiEffectDice` | `true` | 自动封禁 `Dice_` 后含 ≥2 个数字段的多效果骰 |
| `General:ExtraBlock` | `revivetp,teleRez` | 额外封禁子串（逗号分隔，不区分大小写） |
| `General:Allow` | 空 | 强制保留的子串 |
| `General:DebugLog` | `false` | **Debug 开关，默认关闭**；开启后打印全量骰子名单 + 每个骰子的判定日志（用于排查） |

## 混沌判定规则（按身份）

1. 名字/别名含 `chaos` → 封。
2. camelCase 拆词 ≥2 个效果词 → 封（`TeleRez`/`BoomHeal`/`CocoonFire`，**任何没遇到的组合也会自动封**）。
3. `Dice_` 后 ≥2 个数字段 → 封（覆盖未遇到的编号组合 `1_2`/`4_5_6`/`8_9_10` 等）。
4. 命中 `ExtraBlock` 子串 → 封。
5. 命中 `Allow` → 放行。

保留：所有单效果功能骰 + 棋盘点数/祝福/诅咒骰。

## 全量名单 dump（解决"今天没遇到"，默认关闭）

把 `General:DebugLog` 设为 `true` 后，进棋盘时 mod 会把 `ItemManager.AvailableTools` 里**所有可发放工具**打印一次：

```
available tool='...' isDice=... blocked=...
```

正常游玩时 DebugLog 默认关闭，日志只保留关键信息（加载 + 清理混沌数量）。

据此可核对完整混沌骰子集（不依赖当天遇到的）。

## 混沌骰子全集

- 命名组合（日志确认）：`Data-Dice_Chaos_1`、`Data-Dice_Chaos_2`、`Data-Dice_TeleRez`、`Data-Dice_BoomHeal`、`Data-Dice_CocoonFire`
- 编号组合（代码类 `ID_Dice_1_2` / `1_2_3` / `1_6` / `3_4` / `4_5_6` / `5_6` / `8_9_10`）：由"多数字段"规则覆盖
- 单效果保留：`Heal / Boom / Fire / Freeze / Lightning / Teleport / Revive / Cocoon / Gather / Scanner / Light / Pelote / Fireworks / AntiGravity`
- 棋盘系（另一套，保留）：`Dice_Normal_* / Dice_Blessed_* / Dice_Cursed_* / Dice_Blursed_* / NormalDice_*`

## 验证

日志 `BepInEx\LogOutput.log` 中应看到：

```
[NoChaosDice] loaded. ...
[NoChaosDice] DiceBox opened (host) -> purging chaos dice from spawn pools.
[NoChaosDice] ItemManager pool die='...' -> BLOCK
available tool='...' isDice=... blocked=...
```

## 卸载

删除 `BepInEx\plugins\不再混沌\` 整个文件夹即可。
