# 总是打折

让 Invokyr 商店里**所有**商品都打折（原版是随机给部分商品打折）。

- **dll**：`InvokyrAllDiscount.dll`
- **GUID**：`top.juluo.invokyr.alldiscount`
- **插件名**：Invokyr All Discount

## 效果

- 每次进商店，所有在售商品（升级 / 家具 / 小工具 / 消耗品）都按折扣率打折。
- **房主安装即可，所有客户端自动生效**：打折通过游戏内置的 Mirror 同步变量（`price` / `isDiscounted` / `originalPrice`）由服务端广播给所有玩家，客户端无需装任何东西。

## 安装

把 `InvokyrAllDiscount.dll` 放到（已替你放到）：

```
Steam\steamapps\common\Invokyr\BepInEx\plugins\总是打折\InvokyrAllDiscount.dll
```

重启游戏，由**房主（Host）**开一局，进商店即可看到全部商品在打折。

## 验证

日志 `BepInEx\LogOutput.log` 中应看到：

```
[Invokyr All Discount] [AllDiscount] loaded. Host-side patch active: ...
[AllDiscount] shop setup complete: N item(s) additionally discounted ...
```

## 卸载

删除 `BepInEx\plugins\总是打折\` 整个文件夹即可（不影响另外两个 mod）。

## 工作原理（技术说明）

- 游戏代码在 `vhs.dll`，商店物品由 `_200_Dev.EnvironmentElements.Shop.ShopItemSlotsManager` 管理。
- 原逻辑：`SrvDiscountOneSlot<T>` 随机给**一个**槽位打折。
- 本 mod 用 Harmony postfix 挂钩 `ShopItemSlotsManager.SrvInstantiateItems()`，遍历四类槽位，对每个未打折槽位调 `SrvApplyDiscount()`。
- `SrvApplyDiscount` 写 Mirror 同步变量，服务端改动自动同步到所有客户端，因此只需房主装。
