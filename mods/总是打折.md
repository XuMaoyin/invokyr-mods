# 总是打折

让 Invokyr 商店里**所有**商品都打折（原版是随机给部分商品打折），且折扣倍率可调。

- **dll**：`InvokyrAllDiscount.dll`
- **GUID**：`top.juluo.invokyr.alldiscount`
- **插件名**：Invokyr All Discount
- **版本**：1.2.1

## 效果

- 每次进商店，所有在售商品（升级 / 家具 / 小工具 / 消耗品）都打折。
- 折扣倍率可调：**最终价 = 原价 × 倍率**（默认 `0.7` = 7 折；设 `0.1` 就是原价 1 折）。
- **房主安装即可，所有客户端自动生效**：打折通过游戏内置的 Mirror 同步变量（`price` / `isDiscounted`）由服务端广播给所有玩家，客户端无需装任何东西。

## 配置

首次加载后生成 `BepInEx\config\top.juluo.invokyr.alldiscount.cfg`，可在游戏内用「配置修改」mod 按 F8 调整，或直接编辑该文件：

- `Enable`（布尔，默认 `true`）：总开关。关闭后本 mod 完全不干预商店价格。
- `Discount`（小数，默认 `0.7`）：打折倍率，`最终价 = 原价 × 倍率`，建议范围 `0.0 ~ 1.0`。

## 安装

把 `InvokyrAllDiscount.dll` 放到（已替你放到）：

```
Steam\steamapps\common\Invokyr\BepInEx\plugins\总是打折\InvokyrAllDiscount.dll
```

重启游戏，由**房主（Host）**开一局，进商店即可看到全部商品在打折。

## 验证

日志 `BepInEx\LogOutput.log` 中应看到：

```
[Invokyr All Discount] [AllDiscount] loaded. Host-side patch active (Enable=True, Discount=0.7)
[AllDiscount] shop setup complete: N item(s) discounted (factor=0.7)
```

## 卸载

删除 `BepInEx\plugins\总是打折\` 整个文件夹即可（不影响其它 mod）。

## 工作原理（技术说明）

- 游戏代码在 `vhs.dll`，商店物品由 `_200_Dev.EnvironmentElements.Shop.ShopItemSlotsManager` 管理。
- 本 mod 用 Harmony postfix 挂钩 `ShopItemSlotsManager.SrvInstantiateItems()`，遍历四类槽位（升级 / 家具 / 小工具 / 消耗品）。
- 对每个槽位：先调游戏的 `SrvApplyDiscount()` 得到游戏折扣价（原价 × 0.7），**再除以 0.7 反推回原价**（避免直接读原价字段在生成阶段的时序问题），最后乘 `Discount` 倍率作为最终价写入 `price` 并标记 `isDiscounted`。
- `price` / `isDiscounted` 是 Mirror 同步变量，服务端改动自动同步到所有客户端，因此只需房主装。
