# 配置修改（Invokyr Config Mod）

游戏中按 **F8** 打开 / 关闭一个配置编辑面板，用来修改其它 Invokyr mod 的配置，改完点 **保存并生效** 立即生效，并自动写回 `BepInEx/config/*.cfg`。

- **GUID**：`top.juluo.invokyr.configmod`
- **装机**：`InvokyrConfigMod.dll` 放到 `BepInEx/plugins/配置修改/`
- 只改房主端即可（面板在本地显示，改的是本地配置）

## 使用

1. 游戏内按 **F8** 弹出面板。
2. 面板按 mod 分 **Tab**（总是打折 / 不再混沌 / 可控祝福…），点 Tab 切换。
3. 界面已**汉化**；右上角 "语言：中文 ▼" 可切换中 / 英文。
4. 每项为「配置名 + 编辑控件」：布尔项为开/关开关，数字/文本项为输入框。
5. 改好后点 **保存并生效**；点 **关闭** 不改动；再次按 **F8** 关闭面板。

## 可修改项（通用扫描）

面板会**自动扫描所有已加载 mod** 的配置文件（排除 BepInEx 核心与本 mod 自身），每个 mod 一个 Tab，能改**任意** mod 的配置。布尔项为开关，数字/文本项为输入框；非可编辑类型（如枚举）只读显示。

## 汉化词典（可外部修改）

配置项与 Tab 名的中文显示来自一个**汉化词典文件**（UTF-8 编码）：

```
BepInEx\config\配置修改汉化词典.txt
```

- 每行一条 `键=中文名`：
  - 配置项：`插件GUID|配置节|配置键=中文名`（含竖线）
  - Tab（插件名）：`插件GUID=中文名`（不含竖线）
- **首次扫描到某个配置项 / Tab 时，如果词典里还没有，会自动追加进去**，`=` 后放原文占位（如 `top.juluo.invokyr.alldiscount|General|Discount=General / Discount`）——你只需把 `=` 后面的值改成中文，保存并重启游戏即生效，不用自己去核对配置项名。
- 文件内容覆盖内置默认汉化；删除该文件可恢复内置默认。

## 工作原理

- 面板用 Unity 即时模式 GUI（`OnGUI`）绘制，不依赖游戏自带菜单，UI 改动也不受影响。
- F8 通过 GUI 事件流检测，与游戏用哪个输入系统无关。
- 通过 `BepInEx.Unity.IL2CPP.IL2CPPChainloader.Instance.Plugins` 反射枚举所有已加载插件，读各插件 `Config` 的 `ConfigEntry` 列表；保存时写目标 `ConfigEntry<T>.BoxedValue`。
- 改动**立即生效**，同时 BepInEx 自动写回对应 `.cfg` 文件，重启游戏后仍然保留。
